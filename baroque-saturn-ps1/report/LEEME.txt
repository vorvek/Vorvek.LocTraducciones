Este parche traduce al español el disco de extras japonés "バロック レポート CD データファイル"
(Baroque Report - CD Data File, Sting, 1997) para Sega Saturn: galería de imágenes, vídeos, personajes y material de promoción.
Necesitas una copia del disco que coincida con Redump: Baroque Report - CD Data File (Japan), 610-6848, edición no venal
(Hibaihin) (http://redump.org/disc/41883/).
El disco tiene dos pistas: la de datos (pista 1) y una de audio (pista 2).

El parche se aplica a la pista de datos de un volcado con pistas separadas, como los de Redump.

Pistas del disco
----------------
  Pista 1 (datos): "Baroque Report - CD Data File (Japan) (Track 1).bin"
    Original:  CRC32 0fe6dd1c  SHA-1 d1e0498bf85cf4fab9f7a7be0836d249c18c2b84  (174.057.408 bytes)
    Parche:    Baroque Report - CD Data File (Japan) (Track 1) [T-Es Vorvek.Loc v1.0].xdelta
    Resultado: "Baroque Report - CD Data File (Japan) [T-Es] (Track 1).bin"
               CRC32 ec3d9874  SHA-1 9700d7dba75c867b8a66f0aa69672e8f0ceacce0  (176.898.624 bytes)
  Pista 2 (audio): "Baroque Report - CD Data File (Japan) (Track 2).bin"
    Original:  CRC32 5dfebdc6  SHA-1 090e974f78d73a7abce254a436fcfd145785d979  (1.764.000 bytes)
    Esta pista no cambia: déjala como está.
  Cue incluido: "Baroque Report - CD Data File (Japan) [T-Es] (Redump).cue". Usa el archivo nuevo de la pista de datos y las pistas de audio originales, en la misma carpeta.

El archivo nuevo es más grande que el original: las imágenes y los textos en español ocupan más espacio y se colocan
al final de la pista de datos.

Cómo aplicar el parche
----------------------
- Windows: xdelta UI o Delta Patcher. Elige el parche, el archivo original y un nombre para el archivo nuevo.
- Navegador: Rom Patcher JS (https://www.marcrobledo.com/RomPatcher.js/) también admite .xdelta.
- Línea de comandos:
    xdelta3 -d -s "Baroque Report - CD Data File (Japan) (Track 1).bin" "Baroque Report - CD Data File (Japan) (Track 1) [T-Es Vorvek.Loc v1.0].xdelta" "Baroque Report - CD Data File (Japan) [T-Es] (Track 1).bin"

Después de aplicar el parche:
- Pon al archivo nuevo el nombre que indica el .cue (o edita las líneas FILE del .cue).
- Abre "Baroque Report - CD Data File (Japan) [T-Es] (Redump).cue" en el emulador. Para comprobar el resultado, compara el CRC32 o el SHA-1 con los valores de arriba.

Probado en Ymir.

Qué incluye
-----------
- Los 40 textos del menú: descripciones de las 8 secciones, títulos de la Torre del Nervio y textos de las páginas, con una fuente
  nueva de ancho variable con acentos, ñ, ¿ y ¡.
- Imágenes redibujadas en español: pantalla de título (PULSA START), menú y rótulos de las 8 secciones (VÍDEOS, GROTESCOS I y II,
  TORRE DEL NERVIO, PERSONAJES, PROMOCIÓN, CRÉDITOS, FOTOS), nombres de los personajes, créditos del equipo, material de promoción
  (felicitaciones, tarjeta, catálogo, folleto, cuñas de radio) y las tarjetas del visor 3D.
- Subtítulos en español en el vídeo RMV, colocados en la parte superior de la imagen.

Notas
-----
- Las cuñas de radio (CM01 a CM03) y el resto del audio siguen en japonés. Los títulos de las cuñas están en español, y la
  transcripción en español de las tres cuñas está en la página de la wiki.
- Las postales POST1 a POST4 llevan un poema en inglés sobre la ilustración y se mantienen como en el original.
- Los nombres del equipo de desarrollo son nombres de personas y no se traducen.
