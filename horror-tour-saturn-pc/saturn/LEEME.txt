Horror Tour (Sega Saturn) - Traducción al español
Vorvek.Loc Traducciones - versión 1.0
=================================================

Este parche traduce al español el juego japonés "ホラー・ツアー" (Horror Tour, Caravan Interactive, 1995) para Sega Saturn.
El juego original tiene voces en japonés: todas las voces llevan ahora subtítulos en español.
El juego pide un cartucho de RAM de 1 MB.

Hay dos ediciones del disco (T-24301G), y cada una tiene su propio parche en un .zip distinto. Usa el que
coincida con tu copia:
- Versión 1.004: Horror Tour (Japan), Redump 19673 (http://redump.org/disc/19673/).
- Versión 2.002: Horror Tour (Japan) (Rev B) (12M), Redump 83939 (http://redump.org/disc/83939/).

El parche se aplica a la pista de datos (pista 1) de un volcado con pistas separadas, como los de Redump. La pista
de audio (pista 2) no cambia.

Cómo aplicar el parche
----------------------
- Windows: xdelta UI o Delta Patcher. Elige el parche, el archivo original y un nombre para el archivo nuevo.
- Navegador: Rom Patcher JS (https://www.marcrobledo.com/RomPatcher.js/) también admite .xdelta.
- Línea de comandos (versión 1.004; para la 2.002, usa los nombres de su apartado):
    xdelta3 -d -s "Horror Tour (Japan) (Track 1).bin" "Horror Tour (Japan) (Track 1) [T-Es Vorvek.Loc v1.0].xdelta" "Horror Tour (Japan) [T-Es] (Track 1).bin"

Después de aplicar el parche:
- Pon al archivo nuevo el nombre que indica el .cue (o edita las líneas FILE del .cue).
- Deja la pista de audio original en la misma carpeta.
- Abre el .cue incluido en el emulador, con el cartucho de RAM de 1 MB. Para comprobar el resultado, compara el CRC32 o
  el SHA-1 con los valores de arriba.

Probado en Ymir y en MiSTer.

Qué incluye
-----------
- Subtítulos en español para todas las voces: las 152 escenas de vídeo, con la introducción y el final.
- Fuente nueva de ancho variable para los subtítulos, con acentos, ñ, ¿ y ¡.
- Menús y pantallas: título, nueva partida y cargar partida, la tabla para escribir el nombre, las opciones, guardar y
  cargar, y los avisos de la memoria.
- Gráficos con texto: texturas recreadas con el texto traducido.
