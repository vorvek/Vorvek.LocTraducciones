# Vorveloc Traducciones

Este es un repositorio de parches y traducciones para juegos clásicos.

| Juego | Sistema | Estado | Enlace |
|---|---|---|---|
| Laplace no Ma | PC Engine CD | Traducción completa (beta) | [Enlace](https://github.com/vorvek/VorvelocTraducciones/wiki/Laplace-no-Ma) |

Cada proyecto tiene su carpeta con un archivo `.zip` que contiene el parche y las instrucciones para aplicarlo.
Los parches no incluyen el juego: necesitas tu propia copia.
